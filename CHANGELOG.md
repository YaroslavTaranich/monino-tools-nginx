# Changelog

Все заметные изменения инфраструктуры и процесса релиза публикуются в этом файле.
Формат основан на Keep a Changelog, версии следуют SemVer.

## [Unreleased]

## [1.0.7] — 2026-09-18

- Подготовлено удаление переходного контракта галереи в API v2: клиенты читают
  обложки из `tool_images`, migration `009-remove-legacy-tool-image` удаляет
  `tools.image` и может восстановить колонку для контролируемого rollback.
- Release manifest обновлён до `2026.09.18.2`: API и user переведены на
  `2.0.0`, admin остаётся на `1.0.3`.

## [1.0.6] — 2026-09-18

- Release manifest обновлён до `2026.09.18.1`: admin `1.0.3` и user `1.0.4`
  получают обложки из массива `tool_images`; совместимый API остаётся `1.1.0`.
- Релиз подготавливает production-клиенты к последующему удалению legacy-контракта
  в API `2.0.0`.

## [1.0.5] — 2026-09-17

- Release manifest обновлён до `2026.09.17.1`: только API обновляется с `1.0.1`
  до последней совместимой версии `1.1.0`; admin остаётся `1.0.1`, user — `1.0.2`.
- Smoke-тесты различают совместимый API v1 и новый контракт v2, включая состояние
  схемы после application rollback без отката миграций.
- Проверка очистки изображений больше не зависит от legacy-колонки `tools.image`.

## [1.0.4] — 2026-09-16

- Rollback ожидает готовность API, admin и user перед запуском smoke-тестов.
- Release manifest обновлён до `2026.09.16.1`; версии приложений не изменились.

## [1.0.3] — 2026-09-15

- Release manifest обновлён до `2026.09.15.1` для выборочного выпуска user `1.0.2`.
- API и admin остаются на проверенных версиях `1.0.1`.

## [1.0.2] — 2026-09-11

- Проверка component SHA поддерживает release-каталоги, загруженные на VPS через SCP.
- Release manifest обновлён до `2026.09.11.3`; версии приложений не изменились.

## [1.0.1] — 2026-09-11

- Исправлена component CI-проверка SemVer-тегов.
- Release manifest обновлён до проверенной комбинации `2026.09.11.2`.

## [1.0.0] — 2026-09-11

- Зафиксирована первая стабильная инфраструктура Monino Tools.
- Добавлены миграции, проверяемые backup/restore, healthcheck, smoke-тесты и rollback.
- Добавлены независимые версии API, admin и user с общим release manifest.
