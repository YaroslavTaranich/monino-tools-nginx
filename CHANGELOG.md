# Changelog

Все заметные изменения инфраструктуры и процесса релиза публикуются в этом файле.
Формат основан на Keep a Changelog, версии следуют SemVer.

## [1.0.0] — 2026-09-11

- Зафиксирована первая стабильная инфраструктура Monino Tools.
- Добавлены миграции, проверяемые backup/restore, healthcheck, smoke-тесты и rollback.
- Добавлены независимые версии API, admin и user с общим release manifest.
